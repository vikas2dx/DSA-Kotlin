# DSA-Kotlin

A structured repository of Data Structures and Algorithms implemented in Kotlin, focusing on clean code, optimal
time/space complexity, and clear algorithmic explanations.

## 🧭 Quick Folder Navigation

Click any package below to jump directly to its source folder in the repository:

| Topic           | Directory                        | Key Implementations                                                  |
|:----------------|:---------------------------------|:---------------------------------------------------------------------|
| **Arrays**      | [`src/arrays`](src/arrays)       | Array manipulation and traversal problems                            |
| **Basic**       | [`src/basic`](src/basic)         | Foundational programming and math concepts                           |
| **Searching**   | [`src/searching`](src/searching) | Binary Search (`SearchingProgram.kt`)                                |
| **Sorting**     | [`src/sorting`](src/sorting)     | Bubble Sort, Merge Sort                                              |
| **Strings**     | [`src/strings`](src/strings)     | Longest Substring Without Repeating Characters (`StringsProgram.kt`) |
| **Entry Point** | [`src/Main.kt`](src/Main.kt)     | Main runner file for testing implementations                         |
